# Python QR Code Generator

A simple QR Code Generator built with Python.

## Features

- Generate QR Codes from URLs.
- Generate QR Codes from text.
- Generate QR Codes from image URLs.
- Save generated QR Codes as PNG images.

## Requirements

- Python 3.x
- qrcode
- Pillow

## Installation

1. Clone this repository:

```bash
git clone https://github.com/USERNAME/Python-QR-Code-Generator.git
```

2. Navigate to the project folder:

```bash
cd Python-QR-Code-Generator
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the script:

```bash
python main.py
```

Choose the type of QR Code:

1. URL
2. Text
3. Image URL

Enter your data and the QR Code will be generated and saved as a PNG image.
